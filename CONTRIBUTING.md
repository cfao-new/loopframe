# Contributing

1. Open an issue before changing the private Access route contract.
2. Keep all selection and rendering work local.
3. Add a test for every image control, file format, or rollback change.
4. Do not commit credentials, device identifiers, screenshots with identity
   data, or exported controller data.
5. Run `npm test` and `npm run test:ui` before sending a change.

The live console test changes real controller state. Run it only with an
account and device you are authorized to use.
