How to create the account

Open https://<console>/network/default/admins, then choose Network > People. A current Owner or Super Admin must create the role and person.

  1. 1Open Roles, choose Create New Role, select Admin, and name it Loopframe.
  2. 2Set Access to Full Admin. Set Network, Protect, InnerSpace, Control Plane, and every other application to None.
  3. 3Return to People, choose Add New Person, select Admin, and assign the Loopframe role.
  4. 4Turn on Local Account Only. Leave Door Access off unless this person also needs to open doors.
Do not grant All Applications or Super Admin. UniFi does not provide a background only permission. Access Full Admin is the narrowest setting that can upload and apply a GIF. View Only and Door Attendant cannot.
